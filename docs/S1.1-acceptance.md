# S1.1 验收清单

## 功能范围

仅搭建多应用基础工程，**不包含**：

- 微信登录 / OpenID 绑定
- 游客账号、设备试用、会员、订单
- 第三方支付与回调
- Android 客户端、管理后台
- Redis、微服务、动态配置中心

## 验收项

| # | 标准 | 验证方式 |
|---|------|----------|
| 1 | Spring Boot 工程可启动 | `.\gradlew.bat bootRun` |
| 2 | MySQL 连接成功 | 启动日志 / 健康检查 |
| 3 | Flyway 初始化成功 | `flyway_schema_history` + 应用日志 |
| 4 | `apps` 表及约束正确 | DBeaver / 集成测试 |
| 5 | `calculator_vault` 注册成功 | 查询 `apps` |
| 6 | 应用注册服务正常 | `AppRegistryServiceIT` |
| 7 | 基础 API 规范正确 | `ApiResponse` / 错误码 |
| 8 | 健康检查正常 | `GET /actuator/health` → UP |
| 9 | 默认安全策略生效 | 未授权访问 `/api/v1/**` → 401 |
| 10 | 测试通过 | `.\gradlew.bat test` |
| 11 | 文档完整 | `README` + `docs/*` |
| 12 | 未越界实现业务 | 代码审查 |

## 测试覆盖对照

| 需求 | 测试 |
|------|------|
| 应用上下文启动 | `AuroraAppServerApplicationTests` |
| Flyway + apps 表 + 种子数据 | `FlywayAndAppsTableIT` |
| `app_code` 唯一约束 | `FlywayAndAppsTableIT`（真实 DB） |
| `platform + package_name` 唯一约束 | `FlywayAndAppsTableIT`（真实 DB） |
| ACTIVE 可查询 | `AppRegistryServiceIT` |
| DISABLED 不可用 | `AppRegistryServiceIT` |
| 未知 `app_code` | `AppRegistryServiceIT` → `APP_NOT_FOUND` |
| 缺失应用上下文 | `AppRegistryServiceIT` → `APP_CONTEXT_REQUIRED` |
| 未授权业务接口 | `SecurityAndHealthIT` |
| 健康检查 | `SecurityAndHealthIT` |

## 测试环境

```powershell
docker compose -f docker-compose.test.yml up -d
.\gradlew.bat test
```

测试连接默认：`127.0.0.1:3307` / 库 `aurora_app_test`（与开发库 `aurora_app` 隔离）。

## 本地人工抽检

```powershell
# 健康检查
Invoke-RestMethod http://localhost:8080/actuator/health

# 业务接口应 401
try { Invoke-WebRequest http://localhost:8080/api/v1/ping } catch { $_.Exception.Response.StatusCode }
```

DBeaver 查看：

1. 新建 MySQL 连接 → 库 `aurora_app`
2. 打开表 `apps`，确认 `calculator_vault` 一行
3. 打开 `flyway_schema_history`，确认 V1/V2 已成功
