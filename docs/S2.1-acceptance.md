# S2.1 验收清单

## 范围

微信登录、会话签发 / 校验 / 撤销、多 App 隔离。

**不包含**：Android SDK、试用计时、会员、支付、Refresh Token、管理后台。

## 验收项

| # | 标准 | 验证 |
|---|------|------|
| 1 | 新用户可创建账号 | 登录 API / `WechatAuthIT` |
| 2 | 已有用户可恢复 | 重复登录同 userId |
| 3 | 不同 App 账号隔离 | 同 OpenID 不同 userId |
| 4 | Token 安全签发（仅存哈希） | `tokenIsStoredAsHashOnly` |
| 5 | `/me` 正常 | 带 Bearer + X-App-Code |
| 6 | `/logout` 撤销 | 撤销后 40102 |
| 7 | 并发首次登录安全 | `concurrentFirstLogin...` |
| 8 | 自动化测试通过 | `gradlew test` |
| 9 | 不泄露敏感信息 | 响应无 openid/secret/token 明文入库 |
| 10 | 无配置不可假登录 | `WECHAT_CONFIG_MISSING` |
| 11 | 文档完整 | wechat-login / 本文件 |

## 人工验收（PowerShell）

```powershell
cd D:\Android_Work_Server\AuroraAppServer
docker compose -f docker-compose.dev.yml up -d

# 配置 application-local.yml 中微信凭证（真实联调）或先跑自动化
.\bootRun.bat

# 无真实 code 时，用自动化验收：
docker start aurora-mysql-it
.\gradlew.bat test
```

真实微信联调（需有效 code）：

```powershell
Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/v1/auth/wechat/login `
  -Headers @{ "X-App-Code"="calculator_vault"; "Content-Type"="application/json" } `
  -Body '{"code":"<wx-code>"}'
```
