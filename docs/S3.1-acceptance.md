# S3.1 验收清单

## 范围

设备 72 小时试用登记/查询、HMAC、匿名限流。

**不包含**：Android 采集、离线计时实现、会员、支付、Redis、微信改造。

## 验收项

| # | 标准 | 验证 |
|---|------|------|
| 1 | 首次登记成功 | `DeviceTrialIT` / 手工 activate |
| 2 | 重复请求不重置 | 同上 |
| 3 | 72h 到期 EXPIRED | MutableClock 推进 |
| 4 | remainingSeconds ≥ 0 | 测试 |
| 5 | 不延长试用 | 测试 |
| 6 | 跨 App 独立 | 测试 |
| 7 | 禁用/未知 App | 40002 / 40001 |
| 8 | deviceKey 校验 | 40007 |
| 9 | 客户端不能指定时间/状态 | 多余字段被忽略 |
| 10 | 原始 key 不入库 | SQL 断言 |
| 11 | HMAC 稳定且按 App 隔离 | 测试 |
| 12 | 并发只一条 | 测试 |
| 13 | 匿名可访问 | 无 Bearer |
| 14 | 限流生效 | 42901 |
| 15 | S1.1～S2.1 回归 | `gradlew test` |

## 人工验收

```powershell
cd D:\Android_Work_Server\AuroraAppServer
# application-local.yml 配置 aurora.trial.hmac-secret
.\bootRun.bat

Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/v1/trial/device/activate `
  -Headers @{ "X-App-Code"="calculator_vault"; "Content-Type"="application/json" } `
  -Body '{"deviceKey":"manual-acceptance-device-001"}'
```

```powershell
docker start aurora-mysql-it
```
